# Changelog

All notable changes to this project will be documented in this file.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] — 2026-08-22

### Added
- Dashboard mit allen Lautsprechern und Now-Playing-Anzeige
- Internet Radio via RadioBrowser + TuneIn-Kompatibilität
- Spotify-Unterstützung über Gerät-Account
- Preset-Verwaltung (6 physische Tasten)
- Multi-Room Zonen-Management
- Setup-Wizard für neue/zurückgesetzte Geräte
- Automatische Speaker-Discovery via SSDP/UPnP
- Update-Banner bei neuen GitHub-Releases
- Docker-Support für amd64, arm64, arm/v7
- GitHub Actions CI/CD für automatische Releases
